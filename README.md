# Learning Rust - Rust Programs from the Rust-Lang Online Book

## Overview

As a software engineer who primarily writes Python code in my professional day-to-day job, I have always been curious about lower-level, strongly typed languages such as Rust. My only experience with such languages was a small C class I happened to take as an elective in my undergraduate years, and the stark difference between C and Python cannot be understated. If there's one thing I've learned about myself over the years, however, it's that the things out of reach on the brink of the unknown have always fascinated me, and Rust is no exception.

So, as a means to demystify this known unknown, I plan to go through the rust-lang book and recreating its example programs with my little twist on them. This is is a precursor project in order to better understand the language so I may use it for a grander project that I've always wanted to build - a Dungeons and Dragons Dungeon Master Management system. More on that at a later date.
